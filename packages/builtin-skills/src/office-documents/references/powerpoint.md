# PowerPoint

Use `.pptx` for presentations and visual narratives.

- Establish a theme and a short slide outline before adding shapes.
- Use one main message per slide, a clear title, restrained text, and consistent margins.
- Prefer native text, tables, charts, shapes, and connectors; use uploaded images only from allowed sandbox paths.
- Keep important content inside the safe area and maintain readable contrast and font sizes.
- Add speaker notes when requested; do not add animations or transitions in this release.
- Render screenshots for all relevant slides and check overlap, clipping, alignment, contrast, chart labels, and image distortion.

Batch operations address paths such as `/`, `/slide[1]`, and `/slide[1]/shape[1]`. Use 1-based indexes and inspect the outline again before repairing uncertain paths.
