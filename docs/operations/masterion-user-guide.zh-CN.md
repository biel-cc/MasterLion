# 小宗狮（Masterino）Web 端操作说明

> 适用版本：Masterino `0.0.2`<br>
> 适用对象：小宗狮内部用户<br>
> 适用平台：Web 端（浏览器）<br>
> 产品入口：[https://aihub.bielcrystal.com](https://aihub.bielcrystal.com)

## 1. 产品简介

小宗狮（Masterino）Web 端是公司内部 AI Agent 工作台。它通过 Aihub 统一提供模型能力，让用户可以直接在浏览器中完成 AI 对话、创建专属助手、组织多助手群聊、上传对话附件，以及查看个人模型额度和用量。

小宗狮 Web 端会根据当前账号在 Aihub 中的用户组和托管 Token 权限展示可用模型。用户不需要、也无法在页面中查看 Aihub Token 的真实值。

## 2. 当前可用范围

| 功能                           | 当前状态 | 说明                                                |
| ------------------------------ | -------- | --------------------------------------------------- |
| AI 对话                        | 可用     | 新建对话、切换模型、连续追问和管理话题              |
| 自定义助手                     | 可用     | 创建助手并配置名称、角色、模型等信息                |
| 群聊                           | 可用     | 将多个助手加入同一群组协作                          |
| 对话附件                       | 可用     | 在聊天中上传文件或图片；实际解析能力取决于所选模型  |
| 图片与视频生成                 | 可用     | 从侧边栏“生成”入口进入；可用模型由 Aihub 权限决定   |
| Aihub 模型与用量               | 可用     | 查看绑定状态、模型、人民币额度、请求数和 Token 用量 |
| 通用设置                       | 可用     | 个人资料、外观、语言和基础模型设置                  |
| 任务、文稿、资源库、记忆、社区 | 暂未开放 | 入口可能置灰并显示“敬请期待”                        |
| 高级工作区设置、评测、开发工具 | 暂未开放 | 普通用户不可使用                                    |

> 功能开放范围可能随版本调整。以页面中的实际入口和提示为准。

### 2.1 Web 端页面结构

登录后，Web 端主要由四个区域组成：

1. **左侧主导航**：进入搜索、首页及其他功能页面。尚未开放的入口会显示为置灰状态。
2. **助手与群组列表**：查看、创建和切换个人助手或群聊。
3. **中央工作区**：显示当前对话、助手资料、群聊内容、生成结果或设置页面。
4. **对话输入区**：输入指令、选择模型、添加附件并发送消息。

常用入口：

- **首页**：开始新对话，查看并切换已有助手或群聊。
- **搜索**：查找助手、群组、话题或可访问的功能。
- **生成**：进入图片或视频生成页面。
- **设置**：管理个人资料、外观、语言、Aihub 模型服务和用量信息。

本文后续所说的按钮、侧边栏、输入区和设置页均指 Web 端页面。

## 3. 首次登录

1. 使用浏览器打开小宗狮 Web 端入口。
2. 使用公司分配的账号完成登录。
3. 首次进入后，系统会依据当前账号的邮箱或用户名匹配 Aihub 用户，并绑定可用的托管 Token。
4. 进入任意对话，检查输入框附近是否显示可选模型。
5. 如果没有可用模型，先按“8.1 Aihub 未绑定或没有模型”处理。

登录成功后，助手、群聊、对话记录和个人设置会保存到当前账号。不要在多人之间共用账号。

## 4. 开始第一次 AI 对话

### 4.1 新建对话

1. 点击左侧栏的“首页”。
2. 在输入框中直接描述任务。
3. 检查当前模型；如需更换，点击模型名称并从列表中选择。
4. 按 `Enter` 发送，等待回答完成。
5. 在同一对话中继续追问，系统会保留当前话题的上下文。

建议第一次使用下面这类完整指令：

> 请把下面的会议记录整理成“结论、待办、负责人、截止时间”四部分；信息不完整的地方单独列出，不要自行补充。

### 4.2 如何写清楚需求

一条有效指令通常包含四项信息：

1. **目标**：要完成什么。
2. **背景**：任务面向谁、为什么做。
3. **材料**：需要分析的文本、文件或数据。
4. **输出要求**：格式、语言、长度和限制条件。

例如：

> 你是公司内部培训助理。根据我上传的制度文件，为新员工整理一份 10 分钟可读完的入职须知。使用中文，按“必须完成、禁止事项、常见问题”分组；每条结论注明来自文件的哪一部分。

### 4.3 选择模型

模型列表由 Aihub 按当前用户组和托管 Token 权限下发。不同用户看到的模型可能不同。

- 日常问答、翻译和摘要：优先选择响应较快的通用模型。
- 复杂分析、代码和长文档：选择推理或长上下文能力更强的模型。
- 图片理解：选择支持视觉识别的模型。
- 图片或视频生成：从“生成”入口选择对应能力的模型。

如果上传图片后提示“当前模型不支持视觉识别”，请切换到支持视觉能力的模型后重试。

### 4.4 管理对话

在助手的对话页面中可以：

- 新建话题，避免不同工作相互污染上下文；
- 修改话题名称，便于后续查找；
- 重新生成不满意的回答；
- 复制需要复用的内容；
- 删除不再需要的话题或消息。

涉及同一项目的连续工作尽量放在同一话题中；完全不同的任务应新建话题。

## 5. 使用文件和图片

1. 在对话输入区点击附件按钮。
2. 选择需要上传的文件或图片。
3. 等待上传完成后，再在消息中明确说明希望如何处理附件。
4. 发送消息并检查回答是否引用了附件中的具体信息。

推荐写法：

> 只根据附件内容回答。先列出三个关键结论，再用表格整理风险、影响和建议；找不到依据时明确写“附件未提供”。

注意事项：

- 上传前确认文件中不包含无关的敏感信息。
- 文件已成功上传，不代表当前模型一定支持该格式；如解析失败，可尝试转换为 PDF、常见图片格式或纯文本。
- 当前资源库和自动向量化能力尚未面向普通用户开放。需要长期复用的资料，应在每次相关对话中重新确认附件是否可用。

## 6. 创建和使用助手

助手适合承载重复使用的角色、规则和默认模型，例如“会议纪要助手”“代码审查助手”或“制度问答助手”。

### 6.1 创建助手

1. 点击助手列表附近的“+”，选择“创建助手”。
2. 填写助手名称和用途。
3. 在角色或系统提示词中写明：
   - 它负责什么；
   - 它应遵守哪些规则；
   - 它应如何组织输出；
   - 哪些事情不能自行决定。
4. 选择默认模型。
5. 保存后，发送一条测试消息验证效果。

可直接参考下面的角色模板：

> 你是小宗狮内部的会议纪要助手。只整理用户提供的会议内容，不补写未发生的事实。输出顺序固定为：会议结论、行动项、负责人、截止时间、待确认问题。行动项必须使用表格；缺少负责人或截止时间时标记为“待确认”。

### 6.2 调整助手

如果回答不稳定，优先修改助手角色中的规则，而不是每次在消息里重复补充。建议一次只调整一类问题，并用同一组测试问题对比修改前后的结果。

不要在助手提示词中写入密码、Token、身份证号等敏感信息。

## 7. 创建群聊

群聊适合让多个分工不同的助手围绕同一任务协作，例如由“资料分析助手”“方案助手”和“审校助手”共同处理一份方案。

1. 点击助手列表附近的“+”，选择“创建群组”。
2. 设置群组名称。
3. 将需要协作的助手加入群组。
4. 在群组说明中明确每个助手的职责。
5. 发起任务时写明最终交付物和判断标准。

示例：

> 请协作审查这份项目方案：资料分析助手检查事实和缺失信息，方案助手提出改进方案，审校助手检查表达与格式。最后合并为一份意见，按“必须修改、建议修改、可保留”分级。

群聊会增加模型调用次数和额度消耗。简单任务优先使用单个助手。

## 8. 查看 Aihub 状态、模型和用量

### 8.1 Aihub 未绑定或没有模型

1. 打开“设置”。
2. 进入模型服务或服务商页面，选择“Aihub”。
3. 检查“Aihub绑定情况”：
   - **已绑定 / 正常**：账号已匹配；
   - **未绑定**：当前小宗狮账号未匹配到 Aihub 用户；
   - **异常**：同步过程失败，可查看页面错误信息。
4. 已绑定时点击“刷新模型”，重新同步当前账号可用模型。
5. 刷新后返回对话页面，重新打开模型列表。

如果仍未绑定，请联系内部管理员核对小宗狮账号与 Aihub 账号的邮箱或用户名。请勿向任何人发送 Token 值。

### 8.2 查看余额与消耗

在 Aihub 详情或用量页面可以查看：

- 当前用户组；
- 可用余额和已用金额，金额以人民币显示；
- 请求次数；
- Prompt Token、Completion Token 和 Total Token；
- 近 14 天趋势；
- 各模型用量和最近请求记录。

模型消耗异常时，先确认是否使用了高成本模型、超长上下文、群聊或重复生成，再联系管理员排查。

> 页面中的“托管 Token”选择项当前主要用于查看可用项，不代表已经切换了实际绑定关系。

## 9. 图片与视频生成

1. 点击侧边栏的“生成”。
2. 选择图片或视频生成页面。
3. 选择当前账号可用的生成模型。
4. 输入主体、场景、风格、构图、比例和不希望出现的内容。
5. 生成后检查结果；需要调整时，每次只修改一到两个条件。

示例：

> 生成一张 16:9 的内部培训封面图：深绿色与金色为主色，主题是“AI 助手提升工作效率”，画面简洁、专业、留出右侧标题区域，不要出现第三方品牌标识。

生成内容应遵守公司数据安全、版权和品牌规范。不要上传未获授权的人像或机密素材。

## 10. 常见问题

### 回答内容明显不准确

- 要求助手只根据指定材料回答并标注依据。
- 把问题拆成较小步骤。
- 补充缺失的背景和输出标准。
- 切换更适合复杂推理的模型。
- 对重要结论进行人工复核。

### 回答中断或长时间没有响应

- 检查网络后重新生成。
- 缩短单次输入或拆分长文件。
- 切换其他可用模型。
- 查看 Aihub 余额和用量是否正常。

### 看不到某个模型

小宗狮只展示当前 Aihub 用户组和托管 Token 允许使用的模型。先在 Aihub 设置页点击“刷新模型”；仍不可见时联系管理员确认权限。

### 侧边栏功能显示“敬请期待”

该功能当前尚未开放，不是账号故障。现阶段请优先使用对话、助手、群聊、附件和生成能力完成任务。

### 上传图片后无法识别

当前模型可能不支持视觉识别。切换到支持图片理解的模型，再重新发送附件和问题。

## 11. 安全与使用规范

- 不在提示词、助手配置或共享内容中写入密码、密钥、Token 等凭证。
- 只上传完成工作所必需的资料，并遵守公司数据分级要求。
- AI 输出用于决策、对外发布或执行操作前，必须由责任人复核。
- 涉及财务、法律、人事、安全等高风险事项时，不把 AI 回答作为唯一依据。
- 不尝试绕过 Aihub 的模型权限、额度限制或小宗狮的功能限制。
- 发现账号绑定异常、数据暴露或可疑操作时，立即停止使用并联系内部管理员。

## 12. 推荐的上手路径

1. 完成登录并确认 Aihub 已绑定。
2. 用默认模型完成一次简单问答。
3. 切换模型，对比同一问题的回答。
4. 上传一份非敏感文件，完成摘要或信息提取。
5. 创建一个与日常工作相关的专属助手。
6. 有明确多角色分工时，再创建群聊。
7. 定期查看 Aihub 用量，选择与任务复杂度相匹配的模型。
